# Dynamic Programming

## The DP checklist

1. Define the state.
2. Define the transition.
3. Define base cases.
4. Decide evaluation order.
5. Decide memoization vs tabulation.
6. Check complexity.
7. Look for space optimization.

## Progression

Recursion → memoization → tabulation → space optimization → 1D → grid → knapsack → subsequences → strings → interval/tree/bitmask/digit DP.
