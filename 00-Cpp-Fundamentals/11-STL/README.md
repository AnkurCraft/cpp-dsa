# STL

Learn the standard library as a toolkit, not as magic.

## Containers
`vector`, `array`, `deque`, `list`, `stack`, `queue`, `priority_queue`, `set`, `map`, `unordered_set`, `unordered_map`.

## Algorithms
`sort`, `find`, `count`, `reverse`, `lower_bound`, `upper_bound`, `binary_search`, `min_element`, `max_element`, `accumulate`.

## Rule

Implement a structure from scratch when learning it; use STL when solving a problem unless the exercise specifically asks for a custom implementation.
