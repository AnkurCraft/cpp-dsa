# C++ DSA Roadmap

## Phase 1 — Foundations
- C++ syntax and I/O
- Variables and types
- Conditions and loops
- Functions
- Arrays and strings
- Pointers and references
- Structs and classes
- STL
- Complexity

## Phase 2 — Core problem solving
- Arrays
- Strings
- Searching
- Sorting
- Two pointers
- Sliding window
- Prefix sums
- Hashing

## Phase 3 — Linear data structures
- Linked lists
- Stacks
- Queues
- Deques
- Monotonic structures

## Phase 4 — Recursion
- Recursion fundamentals
- Recursion trees
- Backtracking
- Subsets
- Subsequences
- Permutations
- Constraint problems

## Phase 5 — Trees and heaps
- Binary trees
- Traversals
- BST
- Heap / priority queue
- Tree problem patterns

## Phase 6 — Graphs
- Representation
- BFS / DFS
- Components
- Cycles
- Bipartite graphs
- Topological sort
- Shortest paths
- MST
- DSU
- SCC
- Bridges / articulation points

## Phase 7 — Greedy and DP
- Greedy reasoning
- 1D DP
- 2D DP
- Knapsack
- Subsequences
- Grid DP
- String DP
- Advanced DP

## Phase 8 — Advanced
- Tries
- Fenwick tree
- Segment tree
- Sparse table
- Bit manipulation
- Number theory
- KMP / Z / Manacher
- SCC / flow / advanced graph algorithms

## Recommended progression

**Do not jump directly to DP or advanced graphs.**

Build the prerequisite pattern recognition first.
