# Problem-Solving Patterns

Patterns are the bridge between learning algorithms and recognizing them in unfamiliar problems.

Study these separately from the data structures:

1. Two pointers
2. Sliding window
3. Prefix sum
4. Difference array
5. Fast/slow pointers
6. Binary search
7. Binary search on answer
8. Monotonic stack
9. Monotonic queue
10. Hashing
11. Greedy
12. Backtracking
13. Dynamic programming
14. Graph traversal
15. Topological sorting
16. Union-Find
17. Bitmasking
18. Divide and conquer

For each pattern ask:

**What problem signal suggests it? What invariant does it maintain? Why is the discarded search space safe?**
