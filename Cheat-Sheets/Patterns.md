# Pattern Recognition Cheat Sheet

| Problem signal | Consider |
|---|---|
| Sorted array + pair relationship | Two pointers |
| Longest/shortest contiguous segment | Sliding window |
| Many range-sum queries | Prefix sum |
| Sorted search space | Binary search |
| "Minimum possible maximum" / feasibility | Binary search on answer |
| Nearest greater/smaller | Monotonic stack |
| Connected components | DFS/BFS/DSU |
| Dependencies / ordering | Topological sort |
| Positive weighted shortest path | Dijkstra |
| Negative edges | Bellman-Ford |
| Repeated subproblems | DP |
| Choose among combinations | Backtracking |
| Small universe of boolean choices | Bitmask |
