# Complexity Cheat Sheet

| Technique / Structure | Typical Time |
|---|---:|
| Array index | O(1) |
| Linear search | O(n) |
| Binary search | O(log n) |
| Merge sort | O(n log n) |
| Quick sort | O(n log n) average |
| Hash lookup | O(1) average |
| BST search | O(log n) average; O(n) worst |
| Heap push/pop | O(log n) |
| BFS / DFS | O(V + E) |
| Dijkstra with binary heap | O((V + E) log V) |
| DSU operation | Nearly O(1) amortized |

Always verify the assumptions behind a complexity claim.
