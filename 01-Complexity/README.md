# Complexity Analysis

Before optimizing code, learn to measure it.

## Big-O

Big-O describes how resource usage grows with input size.

Common classes:

- O(1) — constant
- O(log n) — logarithmic
- O(n) — linear
- O(n log n)
- O(n²) — quadratic
- O(2ⁿ) — exponential
- O(n!) — factorial

## What to ask

For every solution:

1. How many times does each loop execute?
2. Are loops nested?
3. Does recursion branch?
4. What extra memory is allocated?
5. Can the algorithm be improved?
