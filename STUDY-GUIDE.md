# How to Study From This Repository

## The 7-step loop

### 1. Learn
Read the topic README.

### 2. Predict
Before opening code, explain the algorithm in your own words.

### 3. Implement
Write it from scratch.

### 4. Analyze
State time and space complexity.

### 5. Test
Try normal cases and edge cases.

### 6. Pattern-match
Ask what signal in a new problem suggests this technique.

### 7. Retrieve
After a few days, solve the problem again without notes.

## If you get stuck

Do not immediately read the solution.

Use this sequence:

**Example → brute force → constraints → observation → pattern → optimized algorithm → implementation**

## For DP

Always write:

`state → transition → base case → order → answer`

## For graphs

Always write:

`representation → traversal/algorithm → visited/state → complexity`

## For binary search

Always write:

`search space → monotonic predicate → invariant → boundary`
