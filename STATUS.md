## Still intentionally expandable

No finite repository can contain literally every DSA problem or every possible implementation. The repository therefore separates:

- **core canonical implementations** — working teaching examples
- **problem bank** — a structured practice catalogue
- **advanced curriculum** — topics to expand as needed

The standard for adding new material is correctness + explanation + complexity + edge cases, not raw file count.
