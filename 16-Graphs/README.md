# Graphs

## Progression

Representation → BFS/DFS → components → cycle detection → bipartite → topological sort → shortest paths → MST → DSU → SCC → bridges/articulation points → flow.

## Choosing an algorithm

- Unweighted shortest path → BFS
- Non-negative weighted shortest path → Dijkstra
- Negative edges → Bellman-Ford
- All-pairs shortest path → Floyd-Warshall
- Minimum spanning tree → Kruskal / Prim
- Dynamic connectivity → DSU
- Dependency ordering → topological sort
