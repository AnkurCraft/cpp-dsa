# Sorting

| Algorithm | Average | Worst | Extra Space |
|---|---:|---:|---:|
| Bubble | O(n²) | O(n²) | O(1) |
| Selection | O(n²) | O(n²) | O(1) |
| Insertion | O(n²) | O(n²) | O(1) |
| Merge | O(n log n) | O(n log n) | O(n) |
| Quick | O(n log n) | O(n²) | O(log n) average recursion |
| Heap | O(n log n) | O(n log n) | O(1) |
| Counting | O(n + k) | O(n + k) | O(k) |

Study stability and in-place behavior too.
